# Assign a subscription

You can assign an existing subscription to a community from the **Subscriptions** page. The assignment workflow covers trials and subscriptions purchased in advance and does not create a new subscription.

## Prerequisites

- You can access the target community.
- An available trial or purchased subscription appears in the assignment list.
- You have permission to manage community subscriptions.

When a new community receives a trial automatically, you do not need to assign it manually. Use this workflow when a trial was not assigned automatically, must be reassigned, or when you need to attach a subscription purchased in advance.

## Assign an existing subscription

1. Open **Subscriptions**.
2. Click **Add subscription**.
3. Click **Assign a subscription**.
4. Use **All**, **Defend**, or **Intelligence** to filter the list when needed.
5. Select the subscription that you want to assign.
6. Click **Assign**.

## Review the available subscriptions

The assignment list can display the information below to help you select the correct subscription.

| Information | Example |
| --- | --- |
| Module and plan | **Defend Prime** |
| Subscription type | **Trial** |
| Duration | Number of days or start and end dates |
| Region | Subscription region |
| Capacity | Number of assets or subscribed volume |
| Retention | Hot storage duration, when available |

Check the subscription details before clicking **Assign**.

The default Defend trial shown in the current workflow runs for 45 days and includes up to 1,000 assets with 7 days of hot storage. Trial specifications may vary if Sekoia changes the available trial offer.

## Subscription missing from the list

If the subscription that you need does not appear, click **Contact us** and provide the module, plan, and target community.

!!! note "Assign and Create are different actions"
    Use **Assign a subscription** when the subscription already exists. Use **Create a subscription** when you need to configure a new subscription in the Self-Service wizard.

## Result

After you assign the subscription, it is attached to the selected community and becomes visible on the **Subscriptions** page. The page displays the subscription period, plan, region, capacity, and remaining time when those values are available.
