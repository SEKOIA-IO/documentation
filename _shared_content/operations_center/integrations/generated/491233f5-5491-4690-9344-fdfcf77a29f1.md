
### Event Categories


The following table lists the data source offered by this integration.

| Data Source | Description                          |
| ----------- | ------------------------------------ |
| `Process monitoring` | The most singular commands of the period, with the user who ran them |
| `Process command-line parameters` | The command lines of those commands, unless the portal redacts arguments |
| `System calls` | AUBE Core analyses the auditd execve records of Linux servers (and process events of Windows servers) |





In details, the following table denotes the type of events produced by this integration.

| Name | Values |
| ---- | ------ |
| Kind | `alert`, `event` |
| Category | `intrusion_detection`, `process` |
| Type | `info` |

| Name | Type | Description                |
| ---- | ---- | ---------------------------|
|`@timestamp` | `date` | Date/time when the event originated. |
|`aube.evaluation.classification` | `keyword` | Analyst classification of the period in AUBE Portal |
|`aube.evaluation.history_id` | `long` | AUBE Portal evaluation history record of the confirmation or withdrawal |

|`aube.evaluation.reviewed_at` | `date` | Time of the last evaluation in AUBE Portal |
|`aube.evaluation.reviewed_by` | `keyword` | AUBE Portal user who confirmed the period, or withdrew the confirmation |

|`aube.event_counts.total` | `long` | Total number of events in the period |
