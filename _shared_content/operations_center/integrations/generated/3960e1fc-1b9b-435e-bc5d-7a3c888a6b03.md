
### Event Categories


The following table lists the data source offered by this integration.

| Data Source | Description                          |
| ----------- | ------------------------------------ |
| `Binary file metadata` | PE metadata and hashes of scanned files and executables |
| `Disk forensics` | MFT, SHIMCache, Amcache and timestomp evidence |
| `DNS records` | DNS cache entries inspected by the DNSCache module |
| `Environment variable` | environment variables inspected by the EnvCheck module |
| `File monitoring` | files scanned by the Filescan, LogScan and Lnk modules |
| `Malware reverse engineering` | YARA and Sigma rule matches on files and events |
| `Process command-line parameters` | command lines of running processes (ProcessCheck) |
| `Process monitoring` | running processes inspected by ProcessCheck/ProcessIntegrity |
| `Process use of network` | per-process connections (ProcessConnections) |
| `Services` | Windows services inspected by the ServiceCheck module |
| `Windows Error Reporting` | crash diagnostics parsed by the WER module |
| `Windows event logs` | event log and EVTX/ETL records matched during the scan |
| `Windows Registry` | registry keys and autostart entries checked by THOR |
| `WMI Objects` | WMI persistence event filters and consumers |





In details, the following table denotes the type of events produced by this integration.

| Name | Values |
| ---- | ------ |
| Kind | `alert` |
| Category | `configuration`, `file`, `host`, `iam`, `intrusion_detection`, `malware`, `network`, `process`, `registry`, `session` |
| Type | `access`, `connection`, `info`, `user` |
